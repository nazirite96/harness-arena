# 참가자 규칙 (초안 v0.1)

1. **제출물**은 제출 계약(§6)을 따르는 opencode 설정 번들만 인정합니다. 번들 루트에 `arena.yaml`, `.opencode/agents/<main_agent>.md` 가 있어야 하며 `arena validate` 를 통과해야 합니다.
2. 기존 에이전트 제품·플러그인(oh-my-opencode / oh-my-openagent 포함)을 **통째로 제출하는 것은 금지**입니다. 코드를 참고하거나 일부 차용하는 것은 허용하되 파일 상단에 출처를 표기합니다.
3. 번들을 만드는 데 Claude Code 등 코딩 에이전트를 쓰는 것은 자유입니다.
4. 인스턴스 ID·레포·이슈를 특정하는 **힌트 하드코딩 금지**. 실행 중 프록시 외의 **외부 네트워크 접근 시도 금지**(격리 환경에서 차단되며 로그에 남습니다).
5. 모델·프로바이더·권한 설정은 운영진이 고정합니다. 번들의 `model`, `provider`, `permission` 항목은 거부됩니다. 모든 에이전트(서브에이전트 포함)는 동일한 고정 모델을 씁니다.
6. **공식 제출**은 팀당 하루 1회, 22:00 KST 마감입니다. dev 실행은 팀 예산(기본 $30) 안에서 무제한입니다. 코드 프리즈는 D9 18:00 입니다.
7. 최종 순위 = Private 해결률 70% + 발표 30%. 상위 3팀은 코드 리뷰·재현 확인 후 확정합니다.
8. 프록시 로그(프롬프트·응답 포함)는 운영진이 대회 운영·교육 목적으로 열람합니다.
9. 위반 시 해당 제출 무효, 반복 시 실격입니다.
