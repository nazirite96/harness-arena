# 작업 지침 (AGENTS.md)

이 저장소의 이슈를 해결하는 것이 목표입니다. 테스트가 통과해야 채점됩니다.

1. 먼저 이슈를 재현하는 최소 스크립트나 테스트를 만든다. 재현 전에는 소스 파일을 편집하지 않는다.
2. 원인이 되는 코드를 `explore` 서브에이전트로 찾고, 수정 범위를 최소화한다.
3. 수정 후 관련 테스트를 실행한다 (`run_related_tests` 도구). 실패하면 되돌리고 다시 시도한다.
4. 새 의존성 설치, 네트워크 접근, git push 는 하지 않는다.
5. 끝낼 때 변경 사항을 한 문단으로 요약한다.
